# Security Policy

## Supported Versions

Horely is a **demo / portfolio showcase** maintained by [Lykos Software Solutions](https://lykos.com.ar). It is not intended for production use without significant modifications (authentication, access control, backups, etc.).

| Version | Supported |
| ------- | --------- |
| `main`  | ✅ Yes    |

## Reporting a Vulnerability

If you find a security issue in this repository, please **do not open a public GitHub issue**.

Instead, report it privately by emailing:

**📧 hola@lykos.com.ar**

Include in your report:
- A description of the vulnerability
- Steps to reproduce it
- Potential impact
- (Optional) A suggested fix

We'll acknowledge your report within **72 hours** and aim to address valid issues as soon as possible.

---

> ⚠️ This project intentionally has **no authentication** on `/admin` — that is by design for demo purposes and is documented in the README. Reports about this are not considered vulnerabilities in this context.
